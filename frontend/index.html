About Records Manager

Records Manager is a web-based application developed for ICT251 Activity 8. It allows users to create, view, update and delete records through a connected frontend and backend system.

How to use

Fill in the record details and select a status to add a record. You can search, filter, view, edit and delete existing records.

System integration

The frontend communicates with a Node.js REST API, which manages records stored in an SQLite database.
